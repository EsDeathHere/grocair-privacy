Kebijakan Privasi Grocair

Privasi Terjaga Penuh Terakhir diperbarui: 19 November 2026

Grocair (aplikasi dengan package com.grocair.app) adalah aplikasi kasir (POS) offline yang dirancang untuk warung dan UMKM. Privasi Anda adalah prioritas mutlak kami. Aplikasi ini tidak memiliki server sendiri dan tidak mengumpulkan, menyimpan, atau menjual data Anda kepada pihak mana pun.

1. Data yang Dikelola

Semua data yang Anda masukkan ke dalam Grocair — meliputi nama warung, daftar barang, stok, harga modal, harga jual, riwayat penjualan/struk, dan PIN pemilik/kasir — disimpan secara eksklusif dan lokal di perangkat Anda menggunakan penyimpanan lokal Android (IndexedDB/WebView Storage).

2. Pembelian & Pembayaran (Google Play Billing)

Untuk transaksi pembelian langganan (Bulanan / Tahunan), pembayaran diproses secara langsung oleh Google Play Billing sesuai dengan Kebijakan Privasi Google. Grocair tidak pernah menerima, melihat, atau menyimpan data kartu kredit, rekening, atau informasi pembayaran Anda. Grocair hanya menerima token konfirmasi pembelian anonim dari Google Play untuk membuka fitur aplikasi.

Pada varian APK Direct, paket dibeli manual melalui WhatsApp penjual +6288294034375. Jika Anda menekan tombol pembelian, nama toko, paket, dan kode instalasi disiapkan dalam pesan WhatsApp; Anda memutuskan apakah pesan dikirim. Pemrosesan pesan mengikuti kebijakan privasi WhatsApp/Meta. Penjual menggunakan informasi pesanan dan konfirmasi pembayaran untuk menerbitkan kode aktivasi dan menangani perpanjangan. Kode aktivasi terikat satu instalasi dan disimpan lokal. Varian Direct tidak menggunakan Google Play Billing untuk aktivasi.

3. Izin Aplikasi (Permissions)

IzinTujuan
INTERNET Hanya digunakan oleh sistem Google Play Billing untuk memvalidasi token langganan resmi saat terhubung ke jaringan. Aplikasi itu sendiri tidak menghubungi server mana pun.
com.android.vending.BILLING Diperlukan untuk memproses transaksi langganan melalui Google Play Store.

Gambar/video kamera tidak pernah disimpan ke file dan tidak pernah diunggah ke server mana pun. Kamera segera berhenti begitu barcode terbaca atau jendela pemindai ditutup.

4. Pelacak & Pihak Ketiga

Grocair tidak memuat Google Analytics, Facebook SDK, Firebase Analytics, cookie iklan, atau alat pelacak pihak ketiga mana pun.

5. Cadangan & Kehilangan Data

Karena tidak ada server cloud terpusat, Anda bertanggung jawab penuh atas keselamatan data warung Anda. Kami menyediakan fitur Unduh backup gratis kapan saja untuk menyimpan data dalam bentuk file JSON di perangkat Anda atau menyalinnya ke media lain.

6. Hak Penghapusan Data

Anda dapat menghapus seluruh data Anda kapan saja melalui tombol Reset data di menu Pengaturan aplikasi, atau dengan mencopot (uninstall) aplikasi dari perangkat Android Anda.

7. Kontak

Jika ada pertanyaan terkait kebijakan privasi ini, Anda dapat menghubungi pengembang melalui repositori resmi atau kontak pengembang di halaman Google Play Store.
